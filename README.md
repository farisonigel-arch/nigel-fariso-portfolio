# Professional Portfolio — Static Provisional Version

This is a fully responsive portfolio built with plain:

- HTML
- CSS
- JavaScript

## Features

- Responsive desktop, tablet and mobile layout
- Sticky navigation
- Mobile navigation menu
- Active navigation state
- Scroll reveal animations
- Skills progress indicators
- Experience timeline
- Filterable project gallery
- Client-side contact-form validation
- Back-to-top navigation
- Accessible skip link
- Reduced-motion support

## Run the portfolio

No installation is required.

1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

For the best local development experience, you can use the VS Code **Live Server** extension.

## Personalisation

Replace:

- `Your Name`
- `your.email@example.com`
- Placeholder social links
- Provisional project descriptions
- Skill percentages

with your actual portfolio information.

The design intentionally follows the current portfolio direction:
dark purple/charcoal background, cyan and green accents, technical cards,
skills, experience, projects and contact sections, but without React,
Taskbar or Sidebar dependencies.
